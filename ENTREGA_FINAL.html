✅ Requisitos Técnicos Implementados

  • Configuração do Projeto: Node.js, Express, TypeScript, .gitignore, scripts npm e ESLint.
  • Modelagem Relacional (Prisma ORM): Entidades Profile, Project, Technology e Feedback.
  • Mapeamento de Relacionamentos: Profile 1:N Project, Project N:N Technology, Project 1:N Feedback.
  • Acesso a Dados & DTOs: Padrão Repository com validações estritas via Zod (títulos não vazios, URLs válidas, e-mails, notas).
  • Endpoints REST: POST e GET implementados para todos os recursos com status HTTP semânticos (200, 201, 400, 404, 409).
  • Coleção Postman: Incluída no repositório com scripts automáticos de ambiente.
  • Testes Automatizados: Suíte completa com Jest e Supertest cobrindo fluxos de sucesso e exceção.
